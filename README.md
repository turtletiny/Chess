# Terminal Chess Game in Java
Run CLI: 
```bash
gradle runCLI -q
```
Run GUI (wip) : 
```bash
gradle run
```

Currently only supports **long algebraic notation**
Example:
```bash
e2 e4 #pawn from e2 to e4
```

```bash
g1 nf3 #knight from g1 to f3
```

**short algebraic notation** is a WIP
